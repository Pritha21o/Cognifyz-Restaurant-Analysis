# Cognifyz Restaurant Analysis

**Restaurant Data Analysis and Machine Learning Internship Projects | Cognifyz**

## About

This repository contains my restaurant data analysis and machine learning internship tasks completed using the restaurant dataset.

## Tasks

### Task 1: Restaurant Rating Prediction

Predict restaurant aggregate ratings using restaurant-related features.

### Task 2: Restaurant Recommendation System

Recommend restaurants based on user preferences such as cuisine, city, and price range.

### Task 3: Cuisine Classification

Classify restaurants based on their cuisine category.

### Task 4: Location-based Analysis

Analyze restaurant locations and geographical patterns in the dataset.

## Project Files

* `Restaurant Rating Prediction.ipynb`
